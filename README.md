# BotForge-AI
BotForge AI پلتفرم ایجنتیک ساخت و نگهداری بات‌های تلگرام و بله است. این ایجنت با دریافت توضیحات متنی کاربر، ابهامات را رفع، منطق برنامه را پیاده‌‌سازی و در محیط Sandbox تست و دیپلوی می‌کند. همچنین قابلیت اعمال تغییرات جدید و آپدیت هوشمند بات را تنها با یک دستور متنی ساده و بدون آسیب به ویژگی‌های قبلی فراهم می‌سازد.
